# Sorbet Hair Studio — demo site

Portfolio demo by [Corivo Digital](https://corivodigital.com). Sorbet is a fictional salon.

Plain HTML/CSS/JS, deploys to Netlify from `main`. Two Netlify Forms: `booking` and `newsletter`.
